## Before updating

- On the command line it's now `@generativenoise/content-tracker`: run it with `npx @generativenoise/content-tracker`, or `npm install -g @generativenoise/content-tracker`. The old package won't be updated.
- Media files are read with a newer ffprobe, which gives the true length of some MP4 and MP3 files - a few hundredths of a second shorter - as it no longer counts the encoder's padding. Their `_duration` changes when they're next read.

## Improved

- Media files are read with FFmpeg 9.1's ffprobe, from 4.4.1.

## Fixed

- The Mac app no longer says it's damaged when downloaded: the first time, choose Done, then **Open Anyway** in System Settings > Privacy & Security.
- The Mac disk image has the app and Applications in the middle of its window.
